# Atividade Acadêmica sobre Arrays em Java.

## Sobre

Programa em Java que cadastra livros em um **array de objetos** e filtra os
resultados usando **manipulação de Strings**.


## Conceitos aplicados

- Array de objetos (Livro[])
- Construtor com parâmetros para inicialização direta
- Laço for para iteração sobre o array
- Método contains() da classe String para filtragem por palavra-chave
